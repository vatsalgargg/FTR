# FTR — Design System

## Principles
- Accessible, clear, responsive, and consistent.

## Foundations
- User supplied Unusually reference screenshots. Match black/white rounded sections, massive condensed headings, diagonal hero collage, persistent pill navbar and interactive service rows. Exact reference fonts from public CSS: Mona Sans Narrow Bold, Mona Sans Regular, DM Mono Regular; self-hosted with OFL licences. Finite eased counters for verified 16 years and established 2010, parallax, pointer tilt, reveals. Native scrolling and motion toggle. No invented percentages, prices or testimonials.

## Accessibility
- Keyboard navigation, visible focus, semantic HTML, labels, contrast, error messages, and reduced-motion support are required.

## Components
- Document component states: default, hover, focus, disabled, loading, empty, and error.
